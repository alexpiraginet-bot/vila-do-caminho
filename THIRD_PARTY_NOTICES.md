# Dependências e ativos
O pacote não distribui bibliotecas, fontes ou áudios de terceiros. O atlas de fallback é desenhado pelas funções Canvas de `public/world.js`.

`public/assets/shore-kit.png` é uma folha de seis objetos gerada com a ferramenta de geração de imagens da OpenAI para este projeto, em 02/11/2026. O arquivo é preservado byte a byte; o jogo recorta os objetos durante o desenho. O manifesto registra seu SHA-256. Nenhuma fotografia pessoal ou imagem de referência privada foi incluída. Não se alega quantização exata à paleta, autoria exclusivamente humana ou fidelidade visual já aprovada. A origem não constitui concessão de licença geral do projeto.

Python e Node são ferramentas externas de desenvolvimento, não redistribuídas neste repositório. Qualquer futura dependência ou ativo deve ter origem e licença verificadas, com avisos preservados. A licença geral do projeto permanece pendente de escolha pelo proprietário.
